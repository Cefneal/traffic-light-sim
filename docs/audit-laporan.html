1. Critical Issues (Harus Segera Dibenerin)

🔴 C1: TL Algorithms Tidak Terhubung ke Sim Controller

Lokasi: app/engine/sim_controller.py + app/engine/tl_algorithms.py

Masalah: File tl_algorithms.py berisi 4 algoritma traffic light (Fixed-Time, Actuated, Max-Pressure, Green Wave) lengkap dengan ALGORITHM_MAP dan get_controller(). Tapi sim_controller._run_loop() hanya memanggil self.traci.simulationStep() tanpa pernah mengimpor atau memanggil algoritma tersebut.

Dampak: Traffic light berjalan dengan logika default SUMO. Pemilihan algoritma di Config Panel tidak berpengaruh sama sekali. Fitur utama aplikasi ini tidak berfungsi.

Fix: Tambahkan di _run_loop() setelah setiap step: 

from app.engine.tl_algorithms import get_controller
tl_ids = self.traci.get_tl_ids()
for tid in tl_ids:
    tl = self._build_traffic_light(tid)
    ctrl = get_controller("fixed", tl, self.traci, self.current_time)
    if ctrl:
        ctrl()

🔴 C2: Tidak Ada Jembatan SUMO → Model Object

Lokasi: app/engine/sim_controller.py + app/models/traffic_light.py

Masalah: Model TrafficLight (di models/traffic_light.py) memiliki field phases: list[TLPhase], algorithm_fn, dll. Tapi tidak ada kode yang membaca data TL dari SUMO (ID, fase, durasi, dll) dan mengisi objek TrafficLight.

Dampak: Model traffic light hanya sebagai definisi kelas, tidak pernah diinstansiasi. Semua algoritma yang menerima parameter tl: TrafficLight akan menerima objek kosong.

Fix: Buat method _build_traffic_light(tl_id) di sim_controller yang: 

def _build_traffic_light(self, tl_id):
    import traci
    logic = traci.trafficlight.getCompleteRedYellowGreenDefinition(tl_id)
    phases = []
    for p in logic[0].phases:
        phases.append(TLPhase(duration=p.duration, state=p.state))
    return TrafficLight(
        id=tl_id,
        current_phase_idx=traci.trafficlight.getPhase(tl_id),
        phases=phases,
        cycle_time=sum(p.duration for p in phases),
    )

🔴 C3: Apply Button Tidak Berfungsi

Lokasi: app/gui/config_panel.py:122-125

Masalah: Method _on_apply() hanya menulis log "Config applied: {get_config()}". Tidak ada perubahan yang diterapkan ke sim_controller, tidak ada sinyal yang dikirim.

Dampak: User bisa mengubah setting di panel config, tapi tidak ada efek apapun.

Fix: 

def _on_apply(self):
    cfg = self.get_config()
    if self.sim_controller and self.sim_controller.is_running:
        self.sim_controller.set_algorithm(cfg["algorithm"])
        self.sim_controller.set_flow_rate(cfg["flow_rate"])
    # Emit signal ke main_window
    self.config_applied.emit(cfg)

2.6 Optimization — P1

  • Batch vehicle updates: Ganti N+1 TraCI calls (get_vehicle_ids → get_vehicle per ID) dengan subscription. Subscribe vehicle variables di awal, baca bulk per step.
  • Caching: Cache TL phases dan edge lists yang jarang berubah. Jangan query tiap step.
  • Async support: sim_controller pake threading, tapi bisa ditingkatkan pake asyncio/QThread biar lebih terintegrasi dengan Qt event loop.

5. Performance Optimization

5.1 TraCI Bottleneck

Masalah utama performa adalah N+1 pattern di map_viewer:

veh_ids = tc.get_vehicle_ids()       # 1 TraCI call
for vid in veh_ids:
    v = tc.get_vehicle(vid)           # N TraCI calls
    # render...

Untuk 300 kendaraan = 301 TraCI calls per frame (setiap 33ms). Solusi: SUBSCRIBE.

# TraCIClient.subscribe_vehicles() — panggil sekali di awal
traci.vehicle.subscribeContext(
    veh_id, traci.constants.CMD_GET_VEHICLE_VARIABLE,
    1000,  # range
    [traci.constants.VAR_POSITION, traci.constants.VAR_ANGLE,
     traci.constants.VAR_SPEED, traci.constants.VAR_TYPE]
)

# Di _update_view — 1 call dapetin semua
vehicle_data = traci.vehicle.getContextSubscriptionResults(veh_id)

5.2 TL Phase Caching

Definisi fase TL jarang berubah. Cache di awal, update hanya saat algo berubah.

5.3 Threading Model

  • SimController: thread daemon ✅
  • TraCI calls dari thread berbeda — perlu lock/queue untuk akses data aman
  • Gunakan QThread / QRunnable untuk integrasi lebih baik dengan Qt event loop

5.4 Memory

  • Dashboard data unlimited — perlu trimming atau pindah ke SQLite
  • Vehicle items di QGraphicsScene — hapus yang sudah keluar, reuse object yang ada (sudah ✅)
  • Network items — sekali load, jangan parsing ulang
