1. Persiapan & Instalasi

1.1 SUMO (Simulation of Urban MObility)

SUMO adalah engine simulasi lalu lintas yang digunakan app ini.

  • Linux (Arch): yay -S sumo
  • Linux (Ubuntu/Debian): sudo apt install sumo sumo-tools
  • Windows: Download installer dari https://sumo.dlr.de/downloads.html

Setelah install, cek:

sumo --version
Catatan: Di Arch Linux, SUMO mungkin terinstall di PATH berbeda. Cek dengan which sumo. Jika tidak ditemukan, tambahkan ke PATH atau install ulang.

1.2 Python & Dependencies

Project ini membutuhkan Python 3.11+.

cd /home/Cefneal/traffic-light-sim
pip install -e .

Atau install manual:

pip install PyQt6 pyqtgraph fpdf2

Cek apakah semua siap:

python3 -c "from PyQt6.QtWidgets import QApplication; print('PyQt6 OK')"
python3 -c "import traci; print('traci OK')"

1.3 Verifikasi Instalasi Lengkap

sumo --version
python3 --version
pip list | grep -E "PyQt|pyqtgraph|traci"
Tip: Jika belum install sebagai package, pastikan folder SUMO_HOME/tools/ ada di PYTHONPATH.

3. Cara Menjalankan App

3.1 Jalankan Aplikasi

cd /home/Cefneal/traffic-light-sim
python -m app.main
Penting: Jalankan dari folder root project, bukan dari folder lain, karena path konfigurasi relatif ke sini.

3.2 Memulai Simulasi

  1. Klik tombol ▶ Play di toolbar atas
  2. Pilih file .sumocfg (contoh: sim/osm_map/test.sumocfg)
  3. Simulasi otomatis berjalan — kendaraan bergerak di peta

3.3 Kontrol Simulasi

TombolFungsi
▶ PlayMulai simulasi baru / lanjutkan dari pause
⏸ PauseJeda simulasi
⏹ StopBerhenti total, reset ke awal
⏭ StepMaju 1 langkah waktu (berguna pas pause)
Slider SpeedAtur kecepatan simulasi (0.1x – 10x)
Tip: Untuk simulasi cepat, naikkan speed slider ke 5x atau 10x. Untuk observasi detail, turunkan ke 1x atau 0.5x.

3.4 Navigasi Peta

  • Drag dengan mouse → geser peta
  • Scroll wheel → zoom in/out

4. Mendapatkan & Menggunakan OSM Map

4.1 Download dari OpenStreetMap

  1. Buka https://www.openstreetmap.org/export
  2. Zoom ke area yang diinginkan (pilih kota/jalan)
  3. Klik Export → download file .osm
Batasan: Export gratis dibatasi area kecil. Untuk area besar, gunakan Geofabrik: https://download.geofabrik.de/

4.2 Import ke App

Cara 1 — Via App:

  1. Buka app: python -m app.main
  2. Menu File → Import OSM...
  3. Pilih file .osm yang sudah didownload
  4. Tunggu proses convert, peta akan tampil

Catatan: App hanya menampilkan peta. Untuk menjalankan simulasi dengan kendaraan, lanjut ke langkah 5-6.

Cara 2 — Via Script (1 langsung jadi):

bash scripts/siapkan_map.sh /path/file.osm

Script ini otomatis:

  1. Convert OSM → network SUMO
  2. Generate rute kendaraan random
  3. Buat file .sumocfg
  4. Output di folder sim/nama_file/

Cara 3 — Manual step-by-step:

# 1. Convert OSM ke SUMO network
netconvert --osm /path/file.osm -o network.net.xml

# 2. Generate rute kendaraan
python3 $SUMO_HOME/tools/randomTrips.py \
    -n network.net.xml -o routes.xml \
    --begin 0 --end 360 --period 2 -r 500

# 3. Buat file konfigurasi
cat > test.sumocfg << 'EOF'
<configuration>
    <input>
        <net-file value="network.net.xml"/>
        <route-files value="routes.xml"/>
    </input>
    <time>
        <begin value="0"/>
        <end value="360"/>
    </time>
</configuration>
EOF

4.3 Parameter randomTrips.py

ParameterFungsiContoh
-nFile network (.net.xml)-n network.net.xml
-oOutput file routes-o routes.xml
--beginWaktu mulai (detik)--begin 0
--endWaktu selesai (detik)--end 360
--periodInterval kendaraan (detik)--period 2
-rRate kendaraan per jam-r 500
--vehicle-classJenis kendaraan--vehicle-class passenger

5. Netedit — Editor Jalan & Traffic Light

5.1 Membuka Netedit

netedit

Atau buka langsung dengan network:

netedit -s network.net.xml

5.2 Cara Menggambar Jalan

  1. Klik tab Network di kiri atas
  2. Pilih mode Edge (jalan)
  3. Klik di canvas untuk menempatkan node (simpang)
  4. Klik node pertama, lalu node kedua untuk membuat jalan di antaranya
  5. Klik kanan untuk selesai

5.3 Menambahkan Traffic Light

  1. Mode Junction → pilih simpang yang ingin diubah
  2. Di panel kanan, set Type → traffic_light
  3. Klik Apply
  4. Simpan: File → Save Network

5.4 Mengatur Fase Traffic Light

  1. Klik Traffic Lights tab di panel kiri
  2. Pilih TL ID yang ingin diedit
  3. Di panel kanan, atur:
    • Duration — durasi fase (detik)
    • State — warna: r (merah), y (kuning), g (hijau), G (hijau prioritas)
  4. Klik Apply untuk menyimpan perubahan

5.5 Shortcut Penting Netedit

6. Membuat Rute Kendaraan

6.1 Generate Routes Otomatis

python3 $SUMO_HOME/tools/randomTrips.py \
    -n network.net.xml \
    -o routes.xml \
    --begin 0 --end 360 --period 2 -r 500

6.2 Membuat Rute Manual

Edit file XML langsung:

<?xml version="1.0" encoding="UTF-8"?>
<routes>
    <vType id="car" accel="2.6" decel="4.5" sigma="0.5"
           length="4.5" maxSpeed="13.89" color="0,0,1"/>

    <route id="r1" edges="e1 e2"/>
    <route id="r2" edges="e3 e4"/>

    <flow id="f1" route="r1" begin="0" end="300" vehsPerHour="360"/>
    <flow id="f2" route="r2" begin="0" end="300" vehsPerHour="360"/>
</routes>
ElemenFungsi
vTypeDefinisi tipe kendaraan (percepatan, ukuran, warna)
routeRute: daftar edge ID yang dilalui
flowAliran kendaraan: route, waktu mulai/selesai, jumlah per jam
vehicleKendaraan individual (alternatif flow)

8. Dashboard & Export Data

8.1 Grafik Realtime

Dashboard (kanan bawah) menampilkan 4 grafik:

  • Avg Wait Time — waktu tunggu rata-rata

9. File .sumocfg — Penjelasan Lengkap

File .sumocfg adalah file konfigurasi simulasi SUMO. Berikut struktur lengkapnya:

<?xml version="1.0" encoding="UTF-8"?>
<configuration>
    <input>
        <net-file value="network.net.xml"/>
        <route-files value="routes.xml"/>
        <additional-files value="detectors.xml"/>
    </input>
    <time>
        <begin value="0"/>
        <end value="360"/>
    </time>
    <processing>
        <time-to-teleport value="-1"/>
        <default.speeddev value="0.1"/>
    </processing>
    <report>
        <no-warnings value="true"/>
        <verbose value="false"/>
    </report>
</configuration>
SectionParameterFungsi
inputnet-fileFile network (.net.xml)
inputroute-filesFile rute kendaraan
timebeginWaktu mulai simulasi (detik)
timeendWaktu selesai simulasi (detik)
processingtime-to-teleportTimeout kendaraan macet (-1 = nonaktif)

10. Troubleshooting

Aplikasi tidak bisa jalan

GejalaPenyebabSolusi
"PyQt6 not available"PyQt6 tidak terinstallpip install PyQt6
"No module named traci"SUMO tools tidak di PATHInstall SUMO, atau set SUMO_HOME
"Connection refused"SUMO tidak bisa startCek which sumo, pastikan binary ada

Simulasi jalan tapi peta kosong

Network belum diload. Pastikan file .sumocfg yang dipilih bener dan net-file mengarah ke .net.xml yang valid.

File .osm tidak bisa diimport

  • Pastikan file adalah OSM XML (bukan JSON/GPX)
  • Pastikan netconvert ada di PATH
  • Coba convert manual: netconvert --osm file.osm -o network.net.xml

SUMO crash / error

Jalankan langsung untuk lihat error:

sumo -c test.sumocfg

Kendaraan tidak muncul

  • Cek routes.xml — pastikan ada flow atau vehicle
  • Cek edge ID di routes cocok dengan edge ID di network
  • Pastikan begin & end di .sumocfg mencakup waktu rute

Lampu merah tidak berubah

Algoritma custom belum terintegrasi. Gunakan default SUMO atau tunggu update P1.
